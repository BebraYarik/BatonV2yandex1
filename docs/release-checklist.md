# Проверка версии 1.0.1

Подготовлено для загрузки в **черновик** Яндекс Игр. Публикация в каталоге и прохождение модерации не выполнены.

## Выполненные проверки

- 35 модульных/контрактных тестов: формулы, ×1/×10/×100/MAX, пределы чисел, пять замесов, одноразовые награды, ранги, миграция, целостность сейвов, восстановление резервной копии, конфликт ревизий/аккаунтов, очередь облака, отказ хранилища/сети, удаление профиля, rewarded/Gameplay/Ready.
- Chromium: первый клик, Enter/Space, касание, 1000 быстрых кликов, покупка с немедленной перезагрузкой, престиж и постоянная покупка с перезагрузкой, заказ, двойное подтверждение удаления, однократный офлайн-доход, RU/EN, фокус/пауза, SDK и рекламные callbacks через mock.
- Размеры окна: 1280×720, 1366×768, 1920×1080, 800×600, 320×568, 360×640, 390×844, 720×1280, 844×390. Проверены все пять вкладок, внутренний скролл, отсутствие внешнего скролла и выхода навигации за экран.
- Четыре случайных события пройдены браузерными касаниями/кликами; длительный тест выполняет 30 минут активного **ускоренного** времени, без подмены результатов реального 30-минутного плейтеста.
- Модель пяти активных циклов: см. `balance.md`; все достигают престижа и ускоряются.
- ZIP собирается по разрешённому списку файлов; корневой `index.html`, относительные локальные ресурсы, отсутствие SDK/тестов/зависимостей, CRC и лимит 100 МБ проверяет `tools/build.py`.
- Реальные скриншоты UI RU/EN: desktop 1280×720, mobile 720×1280 (360×640 при DPR 2). PNG RGB, по два на язык/устройство. Иконки/обложки — отдельные оригинальные SVG-композиции 512×512 и 800×470. MP4 — реальный игровой процесс, 16:9, 720p, без аудиодорожки.

## Известные ограничения

Локальные часы не считаются защищённым серверным временем; античит, ежедневные награды и лидерборды не заявлены. При параллельной игре на устройствах выбирается новая версия сейва, валюты не суммируются. Неполученное случайное событие при перезагрузке пропадает. При отсутствии SDK/Player игра остаётся локальной; при недоступном облаке удаление облачного прогресса не подтверждено до успешной повторной синхронизации. Объём сейва ограничен 180 КБ, значения валюты — 1e100, зданий — 10 000 каждого типа. Поддерживается защита от повреждений данных, не от изменения сейва самим игроком.
