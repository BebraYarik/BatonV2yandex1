# Устройство проекта

- `data.js`: стабильные ID, исходные цены/BPS, рецепты, условия 42 достижений, этапы, скины.
- `state.js`: схема V2, миграция V1, нормализация, ограничение 180 КБ, конечные числа, контрольная сумма FNV-1a (обнаружение случайных повреждений, не защита от читов).
- `economy.js`: независимые от DOM транзакции. `Game` не занимается рекламой или сетью. Престиж проверяет ID текущего цикла: повторное подтверждение старого цикла не выдаёт корочки.
- `save-manager.js`: основная/резервная локальные копии, ревизии, выбор нового валидного источника, привязка к ID Player. Локальная запись важных действий сразу; клики/пассивная выработка объединены до 500 мс, сбрасываются при скрытии/уходе. Облако последовательно, максимум 20 запросов за 5 минут; повтор с задержкой 30–120 с. Неавторизованный Player поддерживается, окно входа не вызывается. Локальные данные другого известного Player не отправляются текущему аккаунту.
- `platform.js`: асинхронный `/sdk.js`, Player без scopes, SDK-язык, Game Ready ровно один раз, Gameplay start/stop, набор причин паузы. Rewarded выдаёт один бонус только из `onRewarded`, не из `onClose`. Повторный показ невозможен до закрытия предыдущего.
- `main.js`: представление, жизненный цикл и короткие события; списки перерисовываются по сигнатуре, счётчики обновляются отдельно. Ожидающие события не сохраняются; полученная награда и счётчик сохраняются сразу. При обновлении незавершённое событие пропадает, но уже выданная награда остаётся.
- `i18n.js`: одинаковые ключи RU/EN, локализованные названия и условия, 48 новостей с порогами этапов. Без сетевых запросов переводов.

Офлайн-выработка рассчитывается только без временных бонусов. Рекламная пауза и уход на рекламу не оплачиваются офлайн. Длительности бустеров — активные секунды; паузы их не расходуют. Закрытие страницы фиксирует последний активный момент. Время с устройства используется только для ограниченного офлайн-дохода; ежедневных наград и обещаний античита нет.

При выборе между валидными локальным и облачным сейвами сначала сравнивается `revision`, затем `lastSavedAt`. Конфликты параллельной игры на нескольких устройствах разрешаются выбором более новой версии, не сложением валют. Игра в нескольких вкладках получает новые локальные версии через событие `storage`; атомарное межустройственное слияние не заявляется.

Полная очистка записывает новый пустой профиль с более высокой ревизией и удаляет V1/резервную копию. При доступном облаке новый профиль ставится в очередь после предыдущего запроса. Недоступное облако не объявляется очищенным; повтор синхронизации сохраняется до восстановления связи.

## Тестовый сейв

Файл `tests/fixtures/prestige-save.json` хранит **тестовые**, а не пользовательские данные: 4 млн батонов, часть зданий, порог престижа. Не входит в выпускной архив. В DevTools отдельного тестового профиля браузера до загрузки страницы установите строковое содержимое файла в ключ `batonEmpireV2` через Local Storage/Application, затем обновите страницу. Не подменяйте этим реальный профиль с нужным прогрессом. Автотесты устанавливают fixture через init-script до выполнения игры. Пересоздать: `node tools/fixtures.js`.

## Материалы и происхождение

SVG-батон, базовая палитра и исходные данные предоставлены пользователем в `batonQWEN.html`. Дополнительный код, композиции иконки/обложки — в этом репозитории. Unbounded и Nunito включены локально из официального Google Fonts с лицензиями SIL OFL в assets/fonts; при запуске сетевых запросов шрифтов нет. Звуки генерируются через Web Audio; сторонние изображения и музыка не используются. Перед публикацией владелец подтверждает права на предоставленный исходник. Иконки интерфейса — системные emoji, вид зависит от ОС. Иконки/обложки — отрисованный SVG-батон, не снимок интерфейса. Скриншоты и видео — реальный игровой процесс с QA-профилем.
