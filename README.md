# Батон: хлебная империя

HTML5-кликер для Яндекс Игр на основе предоставленного `batonQWEN.html`. Тёмная пекарская палитра, SVG-батон и экономика исходника сохранены; логика переработана в независимые ES-модули. Без runtime-зависимостей, CDN и внешних запросов шрифтов.

## Запуск

Нужны Node.js 20+ и Python 3 для упаковки. Используйте существующую копию репозитория; отдельный worktree для облачной задачи не нужен.

```sh
npm ci
npm run dev
```

Сервер слушает порт 5173. Вне Яндекс Игр работает локальный гостевой режим; рекламная кнопка недоступна. В платформенном черновике игра асинхронно загружает `/sdk.js`, инициализирует SDK и Player, затем сообщает Game Ready после восстановления состояния и загрузки иллюстрации. SDK не включается в архив. Внешняя авторизация не требуется.

## Реализовано

- 10 производств с исходными ценами/BPS, покупки ×1/×10/×100/MAX с суммой индивидуально округлённых цен.
- 21 обычное улучшение, 8 постоянных рецептов с рангами, престиж «Новый замес» с корочками (+15% BPS за каждую заработанную корочку).
- 42 достижения, 3 обновляемых заказа, 4 случайных события, 5 этапов, 5 косметических скинов, 48 двуязычных новостей.
- Золотые плюшки, Web Audio, контроль громкости/анимации; мышь, нативные Enter/Space и касания.
- RU/EN, язык SDK и ручной выбор. Гость без входа; локальные сейвы V2 с контрольной суммой, резервной копией и миграцией `batonKlickerV1`.
- Player getData/setData, очередь облака с интервалом минимум 15 секунд, flush для важных операций и повтором при ошибках. Успех показывается только после подтверждённого Promise.
- Офлайн-доход 60% (80% с рецептом), максимум 8 часов, без временных множителей. Паузы SDK, рекламы, фокуса, видимости, модального окна.
- Необязательная rewarded-реклама ×2 BPS на 180 активных секунд; награда только из `onRewarded`, однократно. Полноэкранная реклама и баннеры не используются.
- Полное удаление — только в настройках с двумя подтверждениями; свежий профиль с повышенной ревизией замещает локальные/облачные данные.

## Проверки и сборка

```sh
npm test
npm run balance
# Chromium должен быть установлен; путь можно задать CHROMIUM_PATH.
npm run test:browser
npm run test:soak  # 4 события и 30 минут ускоренного игрового времени
npm run build
```

Браузерные тесты требуют работающего `npm run dev`. `TEST_URL` позволяет проверить другой сервер, в том числе распакованный ZIP. `npm run build` создаёт `dist/baton-yandex-release.zip`, распакованную копию `dist/game` и SHA256; готовый ZIP и хеш также копируются в `releases/` для скачивания с GitHub; в архив входят только `index.html`, `css/`, `js/`, `assets/`. Папки тестов, документов и `node_modules` исключены.

`npm run balance` сохраняет расчёт пяти циклов в [docs/balance.md](docs/balance.md). Это автоматическая модель активной стратегии, не исследование удержания.

Для материалов карточки: `node tools/media.js` (Chromium и системный FFmpeg); браузерные тесты создают реальные RU/EN-скриншоты. Скрипт записи видео использует только тестовое сохранение, никаких средств выдачи валюты в выпускной сборке нет.

- `media/`: иконки 512×512, обложки 800×470, по два десктопных и мобильных скриншота на язык, короткие MP4.
- `tests/fixtures/prestige-save.json`: сохранение для QA; способ применения описан в архитектуре.
- `reference/batonQWEN.html`: исходный референс заказчика, не используется при запуске и не попадает в ZIP.

Проверки SDK в автоматизации используют контрактный mock. Реальные реклама, облако, debug-панель Яндекс Игр, Safari/iOS и физические устройства проверяются владельцем в черновике. Эта версия подготовлена для загрузки в черновик; одобрение модерацией и проверка в аккаунте Яндекса не заявляются.

Версия оформления от 9 ноября 2026: локальные Unbounded/Nunito (SIL OFL в assets/fonts), левитация и свечение круассана, упругая отдача батона и дуги крошек. Анимации учитывают паузу и reduced-motion.

Проверка визуальных правок: `npm run test:visual` (при запущенном dev-сервере, либо с `TEST_URL`). Новый репозиторий: BebraYarik/BatonV2yandex1.

Типографика сверена с исходным HTML: вкладки, заголовки, счётчик батонов, количество зданий и всплывающие числа используют Unbounded; названия производств и основной текст — Nunito. Вкладки и заголовки разделов оформлены в верхнем регистре.
